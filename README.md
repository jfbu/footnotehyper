# footnotehyper

[`footnotehyper`](https://ctan.org/pkg/footnotehyper) LaTeX package development repo and issue tracker.

**MAKE SURE YOUR BUG REPORT PINGS ME (`@jfbu`) ELSE I WILL NOT BE AWARE OF IT**.

## PDF Tagging

`footnotehyper 1.0 2026/11/12` was the first release compatible with the LaTeX `\DocumentMetadata` command, for documents being tagged or not.
